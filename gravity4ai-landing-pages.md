# Gravity For AI — Target Landing Pages (7-Step Framework)
Three core service landing pages. Same section order as the homepage, but each Stakes/Plan/Price section is written specifically for that service's buyer — this is what makes each page independently rankable instead of a reskinned duplicate of the homepage (critical: Google penalizes near-duplicate pages, so despite the shared *structure*, the actual words in Stakes/Value Prop/Explanatory Paragraph must differ meaningfully page to page, as they do below).
